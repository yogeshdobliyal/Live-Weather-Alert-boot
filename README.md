# Live Weather Alert Bot

An automated weather alert system built with n8n.

## Features

- Webhook-based workflow
- Request validation
- Timestamp verification
- Rate limiting
- Weather API integration
- Weather condition checking
- Automated weather alerts
- Conditional workflow logic
- Automated webhook responses

## Technologies Used

- n8n
- JavaScript
- REST APIs
- Webhooks
- JSON
- AI Automation

## Workflow

The workflow receives a request through a webhook, validates the request, checks the city and weather information, evaluates the weather conditions, and generates an appropriate alert.
